# 加入对话历史保存

现在我会选择一个项目然后对话地区才可以交流，然后我希望加入session保存机制。

## 项目为单位对话存储到文件夹当中

数据存储地方：.env当中新加入 DATA_DIR 变量，意思就是数据根文件夹比如: `D:/projects/agent/backend/data`对话的时候，项目是一个文件路径，无法用作文件夹名称，使用hash函数对路经进行hash后获得一个独一无二的value，这个value作为文件夹名称创建在DATA_DIR下方，所以每个项目的对话历史都存储在对应的文件夹当中。

## 对话存储的方式

使用json

保存的是前端通用的展示格式，就是一个个用户提问，模型回答以及工具调用的节点，也就是说写一个anthropic_session_adaptor.py负责anthropic api格式和我们本地存储格式之间的变化，之后开发对话重新加载功能的时候要用得上

## 文件名称？

项目第一次对话发送过来的时候，我当地的yyyy-mm-dd HH:MM:SS的时间戳作为json文件名称

## 什么时候保存或者更新数据？

每次收到message_end的时候，或者因为我点击切换项目的时候就保存落盘一次，注意我点击切换到别的项目的时候可能有工具调用正在执行，或者模型在写工具调用的参数或者正在生成回答，这个时候停止后给这些残缺的节点都补充上数据再保存，比如工具调用的参数不完整没关系，补充上工具调用结果是用户中断即可，然后回答也是直接在最后加入说明是用户中断，希望之后我新加入真正的用户中断功能的时候这个逻辑可以复用
