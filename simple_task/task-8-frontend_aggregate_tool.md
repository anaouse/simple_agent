# 说明

现在前端有MessagesArea和MessagesNode进行展示聊天记录，非常不错，但是当模型连续调用多个工具的时候我希望他们收录到一个可以被折叠的地方

目前只有用户提问节点 工具调用节点 模型回答节点3种类型

我希望对话中连续的工具调用Node被收录到一个更大层次的Node当中，然后这个Node可以折叠与展开，内部才是具体的工作调用Node

纯前端改动，后端无修改。`npm run build` 通过。
